# 🔥 Forest Fire Detection Using CNN

## 📌 Overview
This project uses **Convolutional Neural Networks (CNN)** to detect forest fires from images. The model classifies images into two categories: Fire and No Fire, helping support early wildfire detection and prevention.

## ✨ Features
- 🔥 Fire and No Fire image classification.
- 🧠 Custom CNN model using TensorFlow and Keras.
- 🖼️ Image preprocessing and data augmentation.
- 📊 Model evaluation using accuracy and confusion matrix.
- 🚨 Potential for real-time fire monitoring systems.

## 🛠️ Technologies Used
- Python
- TensorFlow & Keras
- NumPy & Pandas
- Matplotlib & Seaborn
- Jupyter Notebook

## 📂 Dataset
Dataset collected from Kaggle:

🔗 [Forest Fire Dataset](https://www.kaggle.com/datasets/phylake1337/fire-dataset)

**Categories:**
- 🔴 Fire – Images containing fire.
- 🟢 No Fire – Images without fire.

## ⚙️ Model Architecture
Input Image → Preprocessing → CNN Layers → Pooling → Dense Layers → Fire / No Fire Prediction

## 📈 Model Performance
- **Accuracy:** 95%+
- **Optimizer:** Adam
- **Loss Function:** Binary Crossentropy
- **Metrics:** Accuracy, Precision, Recall, F1-Score

## 🚀 Future Improvements
- Real-time fire detection.
- Drone and CCTV integration.
- Automated fire alert notifications.

## 🎯 Conclusion
This project demonstrates the use of deep learning for automated forest fire detection, contributing towards smarter wildfire monitoring and environmental protection.
